# Interview Guide

## 60-second project explanation

> I created a KYB onboarding operations dashboard using 840 synthetic business applications. I designed the dataset and SQL queries, defined funnel, activation, turnaround, SLA, transaction-failure, and data-quality metrics, and built an interactive dashboard with shared filters. The dashboard helps an operations team identify where applicants drop off, which channels underperform, which cases breach SLA, and what root causes require action. I also prepared a BI-ready CSV and example Power BI DAX measures so the same analysis can be implemented in a standard BI environment.

## CV-ready project bullets

- Built an interactive KYB onboarding dashboard covering funnel conversion, activation, turnaround time, SLA compliance, failed transactions, and data-quality monitoring across 840 synthetic records.
- Wrote PostgreSQL queries for KPI reporting, channel comparison, bottleneck analysis, root-cause investigation, anomaly prioritization, and dashboard-freshness checks.
- Prepared a BI-ready CSV and reusable Power BI DAX measures, then translated analytical findings into operational recommendations for partner onboarding, risk-review backlog, and activation failures.

## Questions to prepare for

1. How do you define an activated application and the denominator for activation rate?
2. Why is SLA compliance calculated only on resolved applications in the executive KPI?
3. How would you validate dashboard numbers against the source system?
4. How would you distinguish genuine risk rejection from operational drop-off?
5. What would you investigate first when API latency and failed transactions rise together?
6. How would you communicate a funnel anomaly to Product, Operations, and Engineering?
7. What changes would be needed to connect the dashboard to production data?
